# پیشرفت بک‌اند عملیاتی

دامنهٔ پذیرفته‌شده: NestJS، PostgreSQL محلی از ZIP، Prisma، SaaS چندسازمانی، عضویت و اشتراک، پنل مدیر کل، ۳۱ ماژول، قواعد ایران، مؤدیان/زرین‌پال/sms.ir آزمایشی. Docker از دامنهٔ اجرا حذف شد.

## مراحل

- [x] راه‌اندازی PostgreSQL از ZIP و اسکریپت‌های محلی بدون Docker
- [x] مدل رابطه‌ای، ۵ migration، کنترل دسترسی و جداسازی سازمان‌ها
- [x] ثبت‌نام، نشست، نقش، سازمان و اشتراک
- [x] CRUD هر ۳۱ ماژول، دفتر قطعی، موجودی موزون، تسویه و برگشت
- [x] پایان سال، ۱۰ گزارش و موتور قواعد نسخه‌دار حقوق
- [x] آداپترها و آزمون قرارداد، صف محلی و درخواست واقعی Sandbox زرین‌پال
- [x] پنل مدیر کل، تنظیم اشتراک و ایجاد سازمان و مدیر اولیه
- [x] اتصال صفحات فرانت‌اند به API واقعی
- [x] تست واقعی API/PostgreSQL، هم‌زمانی، جداسازی و مرور صفحات در Chrome
- [x] راهنمای اجرا و backup/restore آزمایش‌شده
- [x] پرداخت تعاملی کاملاً محلی با موفق/ناموفق/انصراف و تمدید یک‌باره
- [x] صندوق ایمیل مرورگری و تأیید یک‌بارمصرف نشانی
- [x] شبیه‌ساز محلی مؤدیان و پیامک با خطای موقت، رد و وضعیت مبهم
- [x] جست‌وجو، فیلتر و صفحه‌بندی SQL، دریافت صفحه‌ای جدول و خروجی همهٔ صفحات
- [x] سنجش فهرست با ۵۰۰۰ رکورد و ۱۰ درخواست هم‌زمان
- [ ] انطباق کامل حقوق/بیمه/مالیات و خروجی فایل‌های رسمی
- [ ] پذیرش واقعی مؤدیان با حساب و گواهی و نشانی رسمی آزمون
- [ ] پرداخت تعاملی کامل و verify واقعی زرین‌پال
- [ ] ارسال واقعی پیامک/ایمیل و الزام تأیید نشانی برای ثبت‌نام عمومی
- [ ] آزمون بار جامع همهٔ عملیات و الزامات انتشار عمومی

کلیدهای حساب آزمایشی سرویس‌های بیرونی در سورس ذخیره نمی‌شوند. آزمون محلی قرارداد از تأیید واقعی ارائه‌دهنده تفکیک خواهد شد.

جزئیات امکانات، محدودیت‌های دامنه و راه ادامه در [BACKEND-OPERATIONS.md](BACKEND-OPERATIONS.md) است. این نسخهٔ محلی به معنای تکمیل تمام الزامات SaaS عمومی یا تأیید قانونی نرم‌افزار نیست.

## نتیجهٔ آخرین بررسی

- TypeScript فرانت‌اند، build تولیدی Next.js و build بک‌اند: موفق.
- تست HTTP و PostgreSQL روی دیتابیس مجزا: ۲۷ تست موفق، بدون شکست؛ شامل استهلاک شمسی، پرداخت و صف محلی، جداسازی صندوق و تأیید یک‌بارمصرف ایمیل.
- مرورگر Chrome: ۱۶۰ بازدید مسیر، بدون خطای JavaScript یا select بومی؛ ساخت سازمان، پلن، پرداخت محلی و جست‌وجوی صفحه‌ای از UI موفق؛ Excel تمام ۱۱ نتیجهٔ فیلترشده از بیش از یک صفحه و به‌روزرسانی خودکار صف موفق؛ کنترل عرض موبایل پنل موفق.
- بررسی وابستگی‌های اجرایی بک‌اند با npm audit: صفر آسیب‌پذیری گزارش‌شده در زمان بررسی.
- پشتیبان‌گیری و بازیابی در دیتابیس جدید: موفق؛ دیتابیس جاری حفظ شد.

آخرین نتیجهٔ مرورگر: `artifacts/backend-review/browser-report.json`.
