# تراز — حسابداری چندسازمانی

رابط فارسی RTL با Next.js، Tailwind CSS، فونت محلی Vazirmatn و تم روشن سبز؛ بک‌اند NestJS، Prisma و PostgreSQL واقعی. اجرای محلی ویندوز بدون Docker و بدون نصب سرویس Windows انجام می‌شود.

## راه‌اندازی

Node.js 24 یا بالاتر، Windows x64 و اینترنت برای نصب اولیه لازم است.

```bash
npm install
npm run local:setup
npm run local:start
```

`local:setup` باینری رسمی PostgreSQL 18.6 را در `.runtime` دانلود می‌کند، دیتابیس محلی روی پورت 55432 می‌سازد، migration و seed را اجرا می‌کند و بک‌اند را build می‌کند. اجرای دوباره داده‌های موجود را پاک نمی‌کند.

برای دفعات بعد:

```bash
npm run db:start
npm run local:start
```

| بخش | نشانی |
| --- | --- |
| ورود | http://localhost:3000/login |
| ثبت‌نام سازمان | http://localhost:3000/register |
| پنل مدیر کل | http://localhost:3000/platform |
| سلامت بک‌اند | http://127.0.0.1:4000/api/health |
| OpenAPI | http://127.0.0.1:4000/docs |

حساب مدیر کل: `owner@taraz.local`. رمز تصادفی در فیلد `adminPassword` فایل خصوصی `.runtime/local-credentials.json` است؛ این فایل و `backend/.env` وارد Git نمی‌شوند. از پنل مدیر کل می‌توانید سازمان و مدیر اولیه بسازید، پلن تعریف کنید و اشتراک را تمدید یا تعلیق کنید. رمز مدیر سازمان جدید فقط در پاسخ ایجاد نمایش داده می‌شود.

## دادهٔ نمایشی روی دیتابیس واقعی

```bash
npm run db:demo
```

سازمان «گروه بازرگانی آوید»، دو شرکت، شعب و نمونه‌های مرتبط با بخش‌های حسابداری ایجاد می‌شوند. حساب `demo@taraz.local` و رمز آن در `.runtime/demo-credentials.json` قرار دارد. اجرای دوباره seed دمو، سازمان موجود را بازنویسی نمی‌کند. حساب‌های ثابت نسخهٔ قدیمی فرانت‌اند دیگر معتبر نیستند.

## امکانات پیاده‌شده

- ثبت‌نام، نشست HttpOnly، نقش و محدودهٔ شرکت، دعوت، بازیابی رمز و تغییر سازمان.
- سازمان‌های مستقل، شرکت و شعب، سال مالی، ارز مبنا و سقف پلن.
- ۳۱ ماژول: اشخاص، کالا/خدمت، انبار، گردش موجودی، خرید و فروش و برگشت‌ها، پیش‌فاکتور، بانک و صندوق، دریافت/پرداخت، انتقال وجه، چک، هزینه/درآمد، حساب‌ها و سند دستی، کارکنان و حقوق، دارایی و استهلاک، فرمول ساخت و تولید، پروژه و هزینهٔ پروژه، شرکت/شعب/سال/ارز/کاربر.
- دفتر دوطرفهٔ قطعی، مبالغ Decimal، موجودی میانگین موزون، تسویهٔ فاکتور، سند برگشت، کنترل هم‌زمانی و بستن سال.
- ۱۰ گزارش مبتنی بر دفاتر، داشبورد، پیوست خصوصی، تاریخچهٔ تغییرات، جست‌وجوی ستون‌ها، انتخاب‌گر جست‌وجودار، چاپ و Excel.
- پنل مدیر کل مستقل برای سازمان، پلن، اشتراک و ممیزی؛ صفحهٔ خرید و تمدید اشتراک مشتری.

سند قطعی قابل بازنویسی یا حذف نیست؛ اصلاح با سند برگشت و دلیل انجام می‌شود. فایل قدیمی `.data/taraz.json` به دیتابیس جدید وارد نشده و منبع API نیست.

## وضعیت اتصال‌ها و قواعد ایران

| بخش | وضعیت قابل اتکا |
| --- | --- |
| زرین‌پال | درخواست واقعی Sandbox با کد 100 آزمایش شده؛ تأیید و عدم تمدید تکراری با تست قرارداد پوشش دارند. پرداخت تعاملی کامل هنوز با ارائه‌دهنده آزمایش نشده است. |
| مؤدیان | امضا/رمزنگاری، صف پایدار، ارسال و استعلام پیاده شده؛ تأیید انتهابه‌انتها به گواهی، شناسه‌ها و نشانی رسمی محیط آزمون نیاز دارد. پیش‌فرض محلی dry-run است. |
| sms.ir | کلاینت ارسال قالب و تست قرارداد موجود است؛ صف برنامه در حالت آزمایش محلی می‌ماند و پیامک واقعی نمی‌فرستد. Sandbox مستقل رسمی تأیید نشده است. |
| حقوق ایران | موتور قواعد نسخه‌دار و محاسبات سرور وجود دارد؛ قواعد نمونه تأییدنشده‌اند. پوشش کامل قوانین و خروجی رسمی بیمه/مالیات هنوز تکمیل نشده است. |
| ایمیل | لینک دعوت و بازیابی در `.runtime/mail` ذخیره می‌شود. ارسال ایمیل واقعی نیازمند اتصال ارائه‌دهنده است. |

بنابراین این تحویل برای تست محلی کاربردی است؛ ادعای تکمیل انطباق قانونی و آمادگی انتشار عمومی ندارد. جزئیات و کارهای باقی‌مانده در [راهنمای بک‌اند](docs/BACKEND-OPERATIONS.md) آمده است.

## تست و عملیات

```bash
npm run typecheck
npm run backend:build
npm run build
npm run test:backend
npm run test:full
npm run db:backup
npm run db:restore -- .runtime/backups/NAME
npm run local:status
npm run local:stop
npm run db:stop
```

تست بک‌اند دیتابیس مجزا می‌سازد و API را روی 4001 اجرا می‌کند. `test:full` پس از build فرانت‌اند، Chrome نصب‌شده را برای مرور صفحات با سرور 3100 به کار می‌گیرد. دادهٔ اصلی تغییر نمی‌کند. گزارش مرورگر در `artifacts/backend-review/browser-report.json` است. `test:e2e` قدیمی مربوط به API نمایشی قبلی است؛ برای این نسخه از `test:full` استفاده کنید.

پشتیبان در `.runtime/backups` شامل dump دیتابیس و پیوست‌هاست. بازیابی همیشه دیتابیس تازه می‌سازد و دیتابیس جاری را بازنویسی نمی‌کند. کلید رمزنگاری را جداگانه و امن پشتیبان بگیرید. اسکریپت توقف فقط پردازش‌هایی را متوقف می‌کند که خودش شروع کرده است.
